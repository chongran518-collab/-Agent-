# 审计案例

#### 案例1

云南中韬龙和会计师事务所因广西横县某厂投诉其出具的《铜仁市某有限公司财务专项审计报告》弄虚作假，被云南省财政厅立案调查。调查发现：报告列示错报风险但未执行银行函证、存货监盘等程序，未评价错报影响，仅依据往来明细等获取证据，证据不充分。得出“公司财产与股东及关联方独立”的结论，但底稿缺乏对股东及关联方账务核查记录和相关证据，未获取财产独立证明资料。  

违反法律法规：
由于未针对错报风险实施进一步程序、未评价错报影响、审计证据不充分。违反了《中国注册会计师鉴证业务基本准则》第六条、《中国注册会计师审计准则第1251号》第十六条、《中国注册会计师审计准则第1301号》第十条。  由于结论缺乏对股东及关联方账务核查证据，未获取财产独立证明。违反了《中华人民共和国公司法》第六十三条、《中国注册会计师审计准则第1301号》第十条。依据《会计师事务所执业许可和监督管理办法》第六十条、第六十七条，给予该所警告处罚。

#### 案例2

云南省财政厅和省注册会计师协会联合检查云南恒弘会计师事务所有限公司2022年1月至2023年3月执业质量，发现问题并立案调查。经查：注册会计师曹*均、钮*、赵*国在2022年至2023年3月期间签字出具审计报告数量远超合理范围，存在超出胜任能力执业情况。函证、监盘等审计程序执行不到位，证据不充分；部分程序流于形式，记录不完整；注册会计师对助理人员指导复核不足；三级复核仅有签字无具体记录；现金流量表审计无工作底稿。出具的《云南某农业有限公司2022年度审计》：长期股权投资、实收资本等多项科目未实施必要审计程序或证据不足，货币资金未函证，合并范围披露不当。出具的《云南某制药股份有限公司2021年度审计》：生产成本、预收账款等科目未执行审计程序或证据不足，应收账款函证不符未进一步处理，合并范围披露不当，管理层声明书未签字盖章，存货监盘程序缺失。  

违反法律法规：
因注册会计师超出胜任能力执业（2022年度单人签字报告超百份）。违反《会计师事务所执业许可和监督管理办法》（财政部令第97号）第六十二条第九项、《质量控制准则第5101号》第四十一条和第四十四条。因函证、监盘程序不到位，证据不充分；程序流于形式、记录不完整；指导复核不足；复核无具体记录；现金流量表无底稿。涉及《中国注册会计师审计准则》相关程序要求（如证据充分性、程序执行规范等）。
云南某农业有限公司审计违规：长期股权投资、实收资本等科目未实施审计程序或证据不足。货币资金未函证，合并范围披露不当。违反《中国注册会计师审计准则第1301号》第十条（证据充分性）、《中国注册会计师审计准则第1312号》第十二条（函证程序）、《中国注册会计师审计准则第1501号》第五条和第九条（报告披露要求）。  
云南某制药股份有限公司审计违规：生产成本、预收账款未执行审计程序或证据不足。应收账款函证不符未处理，合并范围披露不当，管理层声明书未签字盖章，存货监盘程序缺失。违反《中国注册会计师审计准则第1301号》第十条、《中国注册会计师审计准则第1312号》第十四条/第十九条/第二十一条、《中国注册会计师审计准则第1501号》第五条和第九条、《中国注册会计师审计准则第1341号》第三条、《中国注册会计师审计准则第1311号》第五条。  
依据《会计师事务所执业许可和监督管理办法》（财政部令第97号）第六十条（未履行必要程序、未复核底稿等）、第六十二条（超胜任能力执业）、第六十七条和第六十八条（处罚措施）。给予云南恒弘会计师事务所有限公司警告处罚。

#### 案例3

中准会计师事务所（特殊普通合伙，以下简称“中准所”），为吉林紫鑫药业股份有限公司（以下简称“紫鑫药业”）2013年至2020年年度财务报表审计机构；签字注册会计师刘昆、常明、韩波。、中国证监会调查查明，紫鑫药业2013年至2020年存在未披露关联交易、虚增存货成本及收入利润等违法事实。中准所为其审计期间，2013年出具保留意见审计报告，2014年至2020年出具无保留意见审计报告，但存在以下违法事实：未识别紫鑫药业林下参采购的真实供应商、未关注异常经营风险及非常规交易，未将收入舞弊和存货虚构识别为特别风险，违反审计准则关于风险评估的规定。未对林下参采购业务执行控制测试，仅凭实质性程序得出内控有效的结论，违反审计准则关于控制测试的要求。未设计监盘程序，2014年至2016年未执行监盘且无替代程序，2017年至2020年监盘执行不合理、未记录关键数据，违反存货监盘相关审计准则。函证程序未覆盖关联方异常情况，细节测试未核实交易真实性及资金性质，未关注舞弊风险，违反函证及舞弊责任相关审计准则。  

违反法律法规：
由于未了解林下参行业状况、未识别真实供应商及重大错报风险、未将舞弊风险认定为特别风险。违反《中国注册会计师审计准则1211号》第十四条、第十五条、第二十一条、第二十九条、第三十一条（风险评估要求）；《中国注册会计师审计准则1141号》第二十五条、第二十八条、第三十三条（舞弊风险评估）；《中国注册会计师审计准则1301号》第十条（审计证据充分性）。
因未对林下参采购执行控制测试，仅凭实质性程序确认内控有效。违反《中国注册会计师审计准则1231号》第八条、第十条（控制测试要求）；《中国注册会计师审计准则1314号》第十五条、第十六条、第十七条（审计抽样规范）；《中国注册会计师审计准则1301号》第十条、第十四条（证据充分性与适当性）。  
由于未设计监盘程序、未执行监盘或替代程序、监盘方法不合理、未记录关键数据。违反《中国注册会计师审计准则1311号》第四条、第五条、第七条（存货监盘要求）；《中国注册会计师审计准则1421号》第十条、第十三条（利用专家工作规范）；《中国注册会计师审计准则1231号》第二十六条（应对重大错报风险程序）；《中国注册会计师审计准则1131号》第十条（工作底稿记录要求）。
由于函证程序未覆盖关联方异常、细节测试未核实交易真实性及资金性质。违反《中国注册会计师审计准则1312号》第十四条、第十七条、第二十三条（函证程序规范）；违反《中国注册会计师审计准则1141号》第十三条、第二十四条、第三十三条（舞弊风险应对）；违反《中国注册会计师审计准则1231号》第二十六条（应对重大错报风险程序）；《中国注册会计师审计准则1131号》第十条（工作底稿记录要求）。  
根据《证券法》第一百六十三条（中介机构勤勉尽责义务）、第二百一十三条第三款（未勤勉尽责处罚）； 2005年《证券法》第一百七十三条（中介机构虚假记载责任）、第二百二十三条（处罚规定）。处罚结果：中准所：没收业务收入556.6万元，罚款2226.42万元，暂停证券服务业务3个月；刘昆：警告，罚款100万元； 常明：警告，罚款50万元； 韩波：警告，罚款6万元。

#### 案例4

中审亚太会计师事务所（特殊普通合伙，以下简称“中审亚太”）、签字注册会计师解乐、李家忠；被审计单位为公准肉食品股份有限公司（以下简称“公准股份”）。  
中审亚太对公准股份2014年、2015年年度财务报表审计后出具标准无保留意见报告，但公准股份同期存在虚增银行存款、营业收入、成本及利润等虚假记载。黑龙江证监局调查认定，中审亚太在审计中存在多项程序缺陷：未获取银行结算账户清单、未函证部分账户、未分析大额资金闲置与举债合理性、内控测试无证据支持。销售及采购业务的控制测试未获取订单、出库单等证据，实质性程序未核查发货单、合同等，对自然人客户/供应商未保持职业怀疑。银行存款及应收账款函证缺乏发函回函轨迹、跟函记录等，无法确认函证有效性。内控测试无证据支持，截止测试记录缺失，证据与底稿矛盾。对被审计单位行业、内控等了解错误或矛盾。  
黑龙江证监局据此作出行政处罚，中审亚太与解乐申请行政复议，中国证监会维持原处罚决定。  

违反法律法规：
由于未获取银行账户清单、未函证部分账户、未分析资金异常、内控测试无证据。违反《中国注册会计师审计准则1312号——函证》（2010）第十四条（函证程序要求）；《中国注册会计师审计准则1301号——审计证据》（2010）第十条（证据充分性）；《中国注册会计师审计准则1211号——风险评估》（2010）第二十九条（职业怀疑要求）。  
由于控制测试未获取订单等证据，实质性程序未核查关键单据，未关注自然人客户/供应商异常。违反《中国注册会计师审计准则1301号——审计证据》（2010）第十条；《中国注册会计师审计准则1141号——舞弊责任》（2010）第二十四条（舞弊风险应对）。  
由于函证过程失控，无发函回函轨迹、跟函记录等。违反《中国注册会计师审计准则1312号——函证》（2010）第十七条（函证控制要求）、第二十三条（记录要求）。  
由于内控测试无证据，截止测试记录缺失。违反《中国注册会计师审计准则1311号——存货监盘》（2010）第五条（程序执行要求）；《中国注册会计师审计准则1131号——工作底稿》（2010）第十条（记录要求）。  
因对被审计单位行业、内控等了解错误或矛盾。违反《中国注册会计师审计准则1211号——风险评估》（2010）第十四条（了解被审计单位环境要求）。  

根据《非上市公众公司监督管理办法》（证监会令第96号）第六条（中介机构勤勉义务）、第五十九条（处罚条款）；2005年《证券法》第一百七十三条（中介机构虚假记载责任）、第二百二十三条（处罚规定）。处罚结果：中审亚太：没收业务收入25万元，罚款75万元；解乐：警告，罚款7万元；李家忠：警告，罚款5万元。

#### 案例5

注册会计师戚鹏雄，执业证书编号330002190011，就职于诸暨广信会计师事务所有限公司；相关审计项目涉及XX钢业建筑工程有限公司、XX商贸有限公司2022年度财务报表审计。
根据浙江省财政厅和省注册会计师协会联合检查工作安排，2023年8月检查组对诸暨广信会计师事务所有限公司进行执业质量检查，发现戚鹏雄签署的审计报告存在执业质量问题。在XX钢业建筑工程有限公司2022年度财务报表审计项目（诸广会审字〔2023〕第1359号，签字注册会计师：张广武、戚鹏雄）中，货币资金、短期借款科目未执行函证程序，未说明不予函证理由，未获取已开立银行账户清单，未测算银行借款利息；除货币资金和短期借款科目外，其余科目仅编制审定表等，未执行其他必要审计程序和获取审计证据。在XX商贸有限公司2022年度财务报表审计项目（诸广会审字〔2023〕第1261号，签字注册会计师：张广武、戚鹏雄）中，其他应收款“综合户”未核实具体单位或个人，未执行函证及替代程序；预收账款未获取销售合同核实款项性质，未识别出关联方关系；主营业务成本和营业外支出除编制审定表等外，未执行其他必要审计程序，未获取充分适当审计证据。经浙江省注册会计师协会惩戒委员会决议，决定对戚鹏雄给予“公开谴责”的惩戒，戚鹏雄若有异议，可在规定时间内向申诉委员会提起申诉 。

违反法律法规：
由于货币资金、短期借款未执行函证程序，未说明不予函证理由，未获取已开立银行账户清单，未测算银行借款利息；其余资产负债表和利润表科目仅编制审定表等，未执行其他必要审计程序和获取审计证据。违反《中国注册会计师审计准则第1312号——函证》第十二条、《中国注册会计师审计准则第1301号——审计证据》第十条的规定。
因其他应收款“综合户”未核实具体单位或个人，未执行函证及替代程序；预收账款未获取销售合同核实款项性质，未识别出关联方关系；主营业务成本和营业外支出除编制审定表等外，未执行其他必要审计程序，未获取充分适当审计证据。违反《中国注册会计师审计准则第1312号——函证》第十一条、《中国注册会计师审计准则第1323号——关联方》第十六条、《中国注册会计师审计准则第1313号——分析程序》第四条、《中国注册会计师审计准则第1301号——审计证据》第十条的规定。 

#### 案例6

注册会计师张广武，执业证书编号330002190001，就职于诸暨广信会计师事务所有限公司；涉及XX装饰材料股份有限公司2021年度、XX钢业建筑工程有限公司2022年度、XX商贸有限公司2022年度财务报表审计项目。
2023年8月，浙江省财政厅与省注册会计师协会联合检查诸暨广信会计师事务所有限公司，发现张广武签署的审计报告存在问题。XX装饰材料股份有限公司2021年度审计中，货币资金未执行监盘、函证等程序，固定资产未获取关键证据且未进行多项核查，其余资产负债表科目仅编制基础表格，未执行有效审计程序；XX钢业建筑工程有限公司2022年度审计里，货币资金和短期借款未函证等，其余科目同样仅做基础表格，无有效审计；XX商贸有限公司2022年度审计时，其他应收款未核实明细且未函证，预收账款未核实款项性质与关联方关系，主营业务成本和营业外支出仅编制基础表格，未充分审计。最终，张广武被浙江省注册会计师协会给予“公开谴责”惩戒，可在规定时间内申诉。

违反法律法规：
