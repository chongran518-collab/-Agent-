# 经济责任审计条例

#### 经济责任审计的对象主要包括哪些人员？

经济责任审计的对象主要是党政主要领导干部和国有企事业单位主要领导人员。在党政机关方面，涵盖了地方各级党委、政府、审判机关、检察机关，各级党政工作部门、事业单位和人民团体等单位的正职领导干部，部分情况下也包括主持工作一年以上的副职领导干部。在国有企业层面，包括国有和国有资本占控股地位或者主导地位的企业（含金融机构）的法定代表人，以及虽未担任法定代表人，但实际行使相应职权的董事长、总经理、党委书记等企业主要领导人，这些人员因其在单位经济活动中的关键决策和管理职责而成为经济责任审计的重点对象。

#### 经济责任审计的主要程序有哪些？

经济责任审计有着规范的程序。一般先是审计计划阶段，审计机关根据干部管理监督需要等因素确定审计项目和审计对象，制定年度审计项目计划。接着是审计准备阶段，包括成立审计组、开展审前调查、编制审计实施方案等，为审计实施做好充分准备。然后进入审计实施阶段，审计组通过审查资料、实地调查、询问相关人员等方式获取审计证据，对被审计领导干部履行经济责任情况进行审计。之后是审计报告阶段，审计组起草审计报告，征求被审计领导干部及其所在单位意见，根据反馈情况进行核实和修改完善，最终出具审计报告。最后是审计结果运用阶段，将审计结果报告等材料报送相关部门，推动审计结果的有效运用，如干部考核任免、责任追究等。

#### 经济责任审计中如何界定领导干部的责任？

在经济责任审计中界定领导干部责任是一个关键环节。通常采用责任清单的方式，将领导干部在经济活动中应履行的责任进行细化和明确。责任界定主要依据相关法律法规、政策规定以及干部的职责权限等，分析问题产生的原因、过程和后果，区分是领导干部直接决定、授意、纵容导致的问题，还是由于制度缺陷、监管不力等间接因素引发的问题，从而准确认定领导干部应承担的直接责任、主管责任或领导责任。例如，对于重大经济决策失误，如果领导干部违反决策程序擅自决定，就应承担直接责任；若是由于对下属部门监管不力，导致执行偏差造成损失，则可能承担领导责任。

#### 经济责任审计与其他专项审计的关系如何？

经济责任审计与其他专项审计相互补充、相互促进。一方面，经济责任审计可以涵盖部分专项审计的内容，如在对领导干部进行经济责任审计时，可能会涉及到对其所负责单位的财政财务收支审计、专项资金审计等内容，通过综合审计来全面评价领导干部的经济责任履行情况。另一方面，专项审计也可以为经济责任审计提供重要参考和线索。例如，固定资产投资审计发现的项目建设中的问题，可用于评估领导干部在相关项目决策和管理方面的责任履行情况；经济责任审计中发现的带有普遍性、典型性的问题，又可以为专项审计确定重点领域和方向提供依据，共同推动完善单位内部管理机制和财政资金使用效益的提升。

#### 如何提升经济责任审计的质量和效果？

提升经济责任审计质量和效果需要多方面努力。首先，加强审计队伍建设，通过专业培训、实践锻炼等方式，提高审计人员的政策水平、审计技术和综合素质，使其能够准确把握经济责任审计的重点和难点，熟练运用各种审计方法和工具。其次，完善审计制度和标准，制定科学合理的审计评价指标体系，明确不同类型领导干部的审计内容和重点，规范审计程序和方法，为审计工作提供明确的指引和依据。再者，强化审计结果运用，加强与组织人事部门、纪检监察机关等的协作配合，建立健全审计结果共享、反馈和整改机制，将审计结果作为干部考核、任免、奖惩的重要参考，充分发挥审计监督在干部管理监督中的作用，切实推动审计发现问题的整改落实，提升审计的实际成效。
